NEON//DAY — Gestor de actividades
===========================================

FUNCIONES
- Crear, editar y eliminar actividades.
- Fecha, hora, categoría, prioridad y notas.
- Marcar actividades como pendientes o completadas.
- Buscar y filtrar por estado y categoría.
- Panel con estadísticas y progreso.
- Guardado automático en el almacenamiento local del navegador.
- Exportación CSV compatible con Excel / LibreOffice Calc.
- Exportación JSON como copia de seguridad.

EXPORTAR A EXCEL
Pulsa "CSV / Excel". El archivo usa codificación UTF-8 y separador de punto y coma.
Excel y LibreOffice Calc pueden abrirlo. Si Excel no separa las columnas
automáticamente, usa Datos > Desde texto/CSV y selecciona el delimitador ";".

IMPORTANTE SOBRE LOS DATOS
Los datos se guardan únicamente en el navegador y dispositivo donde se usa la app.
No hay sincronización entre dispositivos. Si borras los datos del navegador,
puedes perder las actividades; exporta periódicamente una copia CSV o JSON.

DISEÑO
La fuente decorativa puede cargarse desde Google Fonts si hay conexión.
La aplicación funciona también sin esa fuente (usará tipografías alternativas).
